# Nova Era HTML5 Prototype v0.1.0

## Запуск
- Самый простой вариант: распакуйте архив и откройте `index.html` в современном браузере.
- Для корректной работы PWA/установки на экран и service worker-подобного офлайн-хостинга используйте HTTPS-хостинг или локальный сервер. Этот прототип сохраняет прогресс в localStorage.
- Для iPhone: разместите файлы на HTTPS-хостинге, откройте ссылку в Safari → Поделиться → На экран «Домой».
- Для Android: откройте HTTPS-ссылку в Chrome → меню → Установить приложение / Добавить на главный экран.

## Реализовано
- Адаптивный интерфейс для узких экранов и safe-area iPhone.
- Навигация: база, кампания, призыв, герои, Печать Пустоты.
- Ресурсы и локальное сохранение прогресса.
- Пошаговая симуляция боя, награды, энергия.
- Призывы x1 / x10, стоимость кристаллов, шанс редкостей R/SR/SSR, гарантия SSR на каждом 10-м призыве.
- Коллекция героев, фильтр редкости, улучшение уровня за монеты.
- Ежедневное задание и первое испытание Печати Пустоты.
- SVG-иконка и manifest для установки как PWA.

## Важно
Это первый клиентский прототип. Сохранение хранится только на этом устройстве/в этом браузере; аккаунта, сервера, синхронизации между устройствами, настоящей сетевой PvP и серверной защиты пока нет. Арт в текущем прототипе сделан CSS-эффектами и emoji-заглушками; далее заменим их оригинальными спрайтами и анимациями.
